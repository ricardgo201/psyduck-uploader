psyduck-uploader

psyduck-uploader is a small personal tool that copies photos and videos from camera memory cards to the owner's own Google Drive account, then checks every file by checksum so the card can be safely formatted.

What it does

  • Runs on the owner's own computer using the open-source rclone program.
  • Signs in to Google Drive with Google's standard sign-in, using the drive.file permission.
  • That permission lets the tool see and manage only the files it creates itself, not the rest of the Drive.
  • Does not delete anything from the memory card.

Who it is for

This app is not offered to the public. It is used by its developer for personal backups. There is nothing to download or sign up for on this site.
