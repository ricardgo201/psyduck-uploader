Privacy Policy

psyduck-uploader · Last updated: 2026-11-18

Summary

psyduck-uploader is a personal tool used by its developer. It does not collect, store, sell or share personal data with anyone. All data stays between the owner's computer and the owner's own Google Drive.

What the app accesses

When the owner signs in with Google, the app requests the https://www.googleapis.com/auth/drive.file permission. This permission lets the app see and manage only the files and folders that the app itself creates in Google Drive. It cannot see any other file in the account.

How data is used

  • Files from a camera memory card are uploaded to a folder in the owner's Google Drive.
  • The app reads the uploaded files back only to compare checksums and confirm the copy is complete.
  • No data is sent to the developer or to any third party, and the app has no servers, analytics or advertising.

Storage of credentials

The sign-in token that Google issues is stored only in a configuration file on the owner's own computer. It is never transmitted anywhere else.

Sharing and retention

Data is not shared, sold or transferred. Files remain in the owner's Google Drive until the owner deletes them. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the date above will be updated.
